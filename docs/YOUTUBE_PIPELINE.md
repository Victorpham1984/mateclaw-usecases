# YouTube Auto-Extraction Pipeline

## Overview
Automatically crawl YouTube channels/playlists, extract AI use cases using AI, and save them as drafts for admin review.

## Architecture
```
YouTube API → Fetch Videos → Get Transcripts → AI Extraction → Save Drafts → Admin Review → Publish
```

## Environment Variables

Add these to your `.env.local` and Vercel:

```bash
# Supabase (required for YouTube pipeline)
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
SUPABASE_SERVICE_ROLE_KEY=your_service_role_key

# YouTube Data API v3 (get from Google Cloud Console)
YOUTUBE_API_KEY=your_youtube_api_key

# OpenRouter API (for AI extraction)
OPENROUTER_API_KEY=your_openrouter_api_key
# Or use LLM_API_KEY as fallback

# Admin password (shared with main MateClaw admin)
ADMIN_PASSWORD=mateclaw2026

# Vercel Cron secret (auto-generated by Vercel, or set manually)
CRON_SECRET=your_cron_secret

# Telegram notifications (optional)
TELEGRAM_BOT_TOKEN=your_bot_token
TELEGRAM_CHAT_ID=your_chat_id

# App URL (for Telegram notification links)
NEXT_PUBLIC_APP_URL=https://mateclaw-usecases.vercel.app
```

## Getting YouTube API Key
1. Go to [Google Cloud Console](https://console.cloud.google.com)
2. Create a project or select existing
3. Enable "YouTube Data API v3"
4. Create an API key under Credentials
5. (Optional) Restrict the key to YouTube Data API v3

## Admin Dashboard

### Access
Navigate to `/admin/youtube` and enter the admin password (`mateclaw2026`).

### Features
1. **Dashboard** (`/admin/youtube`) - Stats overview + manual crawl trigger
2. **Drafts** (`/admin/youtube/drafts`) - Review, edit, approve, publish, reject use cases
3. **Sources** (`/admin/youtube/sources`) - Manage YouTube channels/playlists
4. **Categories** (`/admin/youtube/categories`) - Manage and create categories

### Adding YouTube Sources

**Channel ID:**
- Go to the YouTube channel
- View page source or use a channel ID finder tool
- Format: `UC...` (starts with UC)

**Playlist ID:**
- Open the playlist on YouTube
- Copy from URL: `youtube.com/playlist?list=PLxxxxxxx`
- Format: `PL...` (starts with PL)

### Draft Workflow
```
Draft → Approve → Publish
  ↓
Reject (with reason)
```

### AI Confidence Score
- **≥80%**: High confidence - clearly demonstrated in video
- **50-80%**: Medium - mentioned but not fully shown
- **<50%**: Low - tangential reference

## Cron Job
Configured via `vercel.json` to run daily at 8:00 UTC:
```json
{
  "crons": [{
    "path": "/api/cron/youtube",
    "schedule": "0 8 * * *"
  }]
}
```

## API Endpoints

| Endpoint | Method | Auth | Description |
|----------|--------|------|-------------|
| `/api/pipeline/stats` | GET | None | Pipeline statistics |
| `/api/pipeline/crawl` | POST | Admin | Trigger pipeline run |
| `/api/admin/auth` | POST | None | Admin login (shared) |
| `/api/admin/yt-drafts` | GET | Admin | List drafts |
| `/api/admin/yt-drafts/[id]` | GET/PATCH/DELETE | Admin | CRUD single draft |
| `/api/admin/yt-sources` | GET/POST/PATCH/DELETE | Admin | CRUD sources |
| `/api/admin/yt-categories` | GET/POST/PATCH | Admin | CRUD categories |
| `/api/cron/youtube` | GET | CRON_SECRET | Cron trigger |

## Troubleshooting

### "No transcript available"
Some videos don't have captions. The pipeline falls back to using the video description only.

### "YouTube API quota exceeded"
Free tier allows 10,000 units/day. Consider using playlists (cheaper API calls) or requesting quota increase.

### "OpenRouter API error"
Check that your OPENROUTER_API_KEY is valid and has sufficient credits.
